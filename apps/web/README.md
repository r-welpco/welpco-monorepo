# @welpco/web

Customer-facing Next.js app. Runs on **http://localhost:8081**.

```bash
pnpm dev          # from this directory, or `pnpm dev:web` from the repo root
```

Full documentation: [documentation/apps/web.md](../../documentation/apps/web.md) — routes, API client, PWA, scripts, testing.
See also [documentation/getting-started/setup.md](../../documentation/getting-started/setup.md) for env setup, and [e2e/README.md](e2e/README.md) for Playwright tests.
